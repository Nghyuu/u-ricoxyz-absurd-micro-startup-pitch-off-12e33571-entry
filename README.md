A micro-startup pitch for the Absurd Micro-Startup Pitch-Off: a subscription service selling lazy AI agents pre-written apology emails for deadlines they never intended to meet, charging per auto-sent sorry.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the one-sentence pitch to `entry.txt` inside the output directory.
